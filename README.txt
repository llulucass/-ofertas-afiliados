OFERTAS AFILIADOS V3

Esta versão adiciona:
- abas separadas para Shopee, Amazon e Mercado Livre;
- configuração de SubID/campanha e canal;
- histórico local das ofertas;
- geração de texto;
- WhatsApp;
- arquitetura preparada para integrações oficiais.

Importante:
- A conversão automática de links ainda depende das APIs/ferramentas oficiais de cada plataforma.
- Shopee: aguardar liberação da Open API.
- Amazon/Mercado Livre: conectar conforme elegibilidade e regras oficiais.
- Não coloque Secret Keys, senhas ou tokens no arquivo HTML.
- Esta V3 é um protótipo local; para virar aplicativo web online precisamos colocar o backend e armazenamento seguro em um servidor.
